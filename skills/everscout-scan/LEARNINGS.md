Procedural lessons for [SKILL.md](SKILL.md). Research findings live in [RESEARCH.md](RESEARCH.md); every change is logged in [CHANGELOG.md](CHANGELOG.md); test runs in [TESTS.md](TESTS.md); state in `evergreen.json`. Retired entries go to LEARNINGS-ARCHIVE.md with a reason.

Write an entry the moment a real signal happens: a user correction, the same error twice, a discovered workaround, an environment fact, a stated preference, a failed test or a failure in use. Check existing entries first: add, update, retire, or none.

Lessons inherited from indie-ai-scout (its LEARNINGS, 2026-09-18 to 2026-09-20) are folded into the procedures rather than copied: triage from the saved fetch file; fetch kept threads one at a time; never retry a block within the hour; a thank-you needs its own pace rule; drafts are handed over for pasting.

## Active

- 2026-09-28 `pacing-has-no-process-lock` (environment fact, found reading `es_sources.py` during an all-beats scan). `_wait`/`_mark` read and write `LOCAL/ratelimit.json` with no lock, so two processes waiting on the same host wake at the same moment and burst. Never run `thread` or `new-note` on Reddit threads from subagents while a `fetch` (or another subagent) is using Reddit. What worked: one background loop fetches every beat in turn; subagents do the web searches and non-Reddit items in parallel and append Reddit URLs to a queue file; one serial script then runs `thread` and `new-note` for each queued URL in turn (new-note reads the 30-minute thread cache, so each thread costs one request). Timing: indie-ai-games alone took over 40 minutes (52 Reddit sources, most multireddit windows overflow to one subreddit a minute). A file lock in `_wait`/`_mark` would make parallel distillation (procedure D) safe.
- 2026-09-28 `non-ascii-reddit-url-fails` (failure in use). `thread` on a Reddit URL whose slug has a non-ASCII character (`.../1wryjs1/pokémon_claude_red.../`) fails with `UnicodeEncodeError: 'ascii' codec`, because `reddit_thread_url` passes the slug through unquoted. Workaround: percent-encode the URL (`urllib.parse.quote(url, safe=":/")`) and run `thread` and `new-note` on that. Fix candidate: quote the path in `reddit_thread_url`, or drop the slug and use `https://www.reddit.com/comments/<id>/.rss`.
- 2026-09-28 `subagent-notes-drop-hedges` (failure in use). The procedure-D checker read 18 of 159 subagent-written notes against their sources: 3 ok, 15 needed small fixes, none wrong in substance. The errors cluster in `summary` and the why-it-matters and reception lines, not the method sections: hedges dropped ("in their experience", "seem"), one commenter turned into "several" or a trend, "about" put on an exact number, a vendor's stated reason recast as the scout's reading. So the unsampled notes probably carry the same kind of slip. What to do: put those four patterns in the distil prompt as explicit don'ts, and have the checker sweep every `summary` line, not just three notes per beat.
