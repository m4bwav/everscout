# Vocabulary: global economics and macro

Facets and canonical entities (format: `beats/_template/vocab.md`). People are left out on purpose: the scout tallies institutions, indicators, policies and themes, not individuals.

## How to use this file

Indicator aliases include the common abbreviations; watch for false matches on short ones ("GDP" is safe, "PCE" is safe, "NFP" is safe; "rates" alone is too vague to be an alias).
